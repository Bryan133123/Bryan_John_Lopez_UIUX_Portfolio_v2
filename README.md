# Bryan John Lopez — UI/UX Engineer Portfolio

## 1. Project Overview

This project is a personal portfolio website developed to present my professional background, technical skills, and experience in UI/front-end development and application systems engineering.

The website provides a central location for presenting my profile, skills, and selected work through a web-based user interface.

## 2. Technologies Used

- **HTML5** — Structures the webpage content and sections.
- **CSS3** — Defines the website's visual design, layout, styling, and transitions.
- **JavaScript** — Supports client-side functionality and interactive user interface behavior.
- **Git and GitHub** — Used to maintain and host the project source code.
- **GitHub Pages** — Used to publish the website.

## 3. Project Features

The portfolio is designed to present professional information through a structured web interface.

Features to review in the current implementation include:

- Professional introduction and profile.
- Technical skills and experience sections.
- Portfolio and project presentation.
- Navigation and menu interactions.
- Visual effects and transitions.
- Scroll-based interface behavior, where implemented.
- Layout behavior across different screen sizes, where supported.

## 4. Project Structure

- `index.html` — Main webpage structure and content.
- `about.html, work.html, process.html` — Separate HTML pages / subpages.
- `style.css` — Visual styling and layout rules.
- `script.js` — JavaScript interactions and client-side behavior.
- `README.md` — Project information and setup documentation.

## 5. How to Run Locally

1. Download or clone the repository.
2. Extract the project files if downloaded as a ZIP archive.
3. Open the project folder.
4. Open `index.html` in a web browser.
5. Navigate through the website and verify the available features.

No build step is required for the basic static website.

## 6. Testing and Validation

The website can be manually tested by checking:

- Whether the page loads correctly.
- Whether images, fonts, and other assets appear correctly.
- Whether navigation links and buttons work.
- Whether JavaScript interactions behave as expected.
- Whether the layout remains usable at different screen sizes.
- Whether browser console errors occur.

Only mark tests as completed after performing them.

## 7. Development and Contribution

This portfolio serves as a personal project demonstrating front-end development concepts and web interface implementation.

My contribution should be described according to the actual work I performed on the HTML, CSS, and JavaScript files. The source code can be reviewed to understand the implementation details.

## 8. Deployment

The website is published using GitHub Pages.

To deploy changes:

1. Commit and push the updated files to the appropriate GitHub branch.
2. Verify the GitHub Pages deployment status.
3. Open the published website and check the changes.
