# Bryan John Lopez — UI/UX Engineer Portfolio

GitHub Pages-ready portfolio using only HTML, CSS and JavaScript.

## Publish
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
4. Save and open the generated `github.io` URL.

No build step is required.

## Note
The portfolio content is based on the supplied resume. Public-facing personal contact information is limited to email. Add only project screenshots/details that you are allowed to publish.
